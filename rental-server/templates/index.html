SERVICE FEATURES

01 / PLANS

料金を確認

容量・RAM・CPU・月額を比較してから、使いたいプランを選べます。

02 / CREATE

サーバーを作成

サーバー名、プラン、実行環境を選び、新しいサーバーを作成します。

作成後に管理

Start / Stop / Restart / Logs / Delete はマイサーバーページにまとめています。
