HOW IT WORKS

契約から利用開始まで。

「ボタンを押してサーバーを作る」だけではなく、契約情報を中心に管理します。

01 / ACCOUNT

利用者登録

メールアドレスとパスワードで契約者アカウントを作成します。

02 / CONTRACT

プランを契約

プラン・サーバー名・実行環境を決め、契約IDと更新日を発行します。

03 / PROVISION

サーバーを発行

契約状態に応じて実サーバーを発行し、契約者専用画面から操作します。
